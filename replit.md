# Sporacle

**Temporary preview site** for Destination AI × & being (Trish's spa).

## Stack

- Plain HTML + CSS static site (no build step, no dependencies)
- Google Fonts: Inter + Playfair Display

## How to run

The workflow `Start application` serves the site:

```
python3 -m http.server 5000
```

Open the Replit preview pane or share the public `.replit.dev` URL.

## Files

- `index.html` — landing page
- `styles.css` — all styles
